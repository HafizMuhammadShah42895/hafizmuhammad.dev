📌 What is VoiceFlow?

VoiceFlow is a custom-built background dictation agent that allows you to speak and have your words instantly typed into whatever window is currently active (Notepad, VS Code, Chrome, etc.). It operates via a simple push-to-talk global hotkey and uses Fast-Whisper for high-accuracy, local speech-to-text. It also features a seamless AI grammar polish tool that rewrites your selected text at the press of a button.

Global Dictation

Works entirely in the background. Hold your custom push-to-talk hotkeys, speak, and release. The text magically types itself at your cursor location in any application.

AI Text Polish

Highlight any poorly written text, press your AI preset hotkey, and VoiceFlow will copy it, pass it through an LLM (via Groq or local Ollama) to fix grammar and structure, and instantly paste the corrected version back in place.

✨ All Platform Features

Push-to-Talk Global Dictation

  • • Configurable global hotkeys (e.g., hold W + R, or Alt + Shift) to record.
  • • Automatically pastes transcribed speech precisely where your cursor is focused.
  • • Visual floating overlay indicates when it is "Listening...", "Processing...", or performing an "AI Rewrite...".

On-the-fly AI Grammar Polish

  • • Select any text in any app and press a hotkey to instantly correct grammar and punctuation.
  • • Configurable AI presets allow you to set custom system prompts for different rewriting styles.
  • • Supports both Groq Cloud (LLaMA 3) for blazing-fast inference and Ollama for completely local, offline AI processing.

Local Speech-to-Text

  • • Powered by Faster-Whisper running completely locally on your CPU.
  • • Automatic language detection or strictly lock it to a specific language.
  • • Transcribe pre-recorded audio files via the built-in dashboard.

Desktop Dashboard

  • • Built-in sleek desktop UI (powered by Pywebview and Flask) for easy configuration.
  • • Tweak hotkeys, set API keys, switch dictation languages, and manage startup settings.
  • • Built-in analytics tracking your total dictated word count and sessions.

🛠️ Tech Stack

Core Application

Python, pynput (Global Hotkeys), pyautogui (Auto-typing), pyperclip

Audio Pipeline

PyAudio (Microphone Capture), rolling audio buffers for hardware interrupt safety

AI & Transcription

Faster-Whisper (Local STT), Groq API / LLaMA 3.1 (Cloud LLM), Ollama (Local LLM)

Frontend & UI

Flask, Pywebview (Desktop Window), HTML5/CSS3/JS, Tkinter (Floating Overlay)

Packaging

PyInstaller & Inno Setup (.iss) for Windows Executable deployment

🚀 Key Achievements

  • Engineered a global voice-to-text dictation agent in Python that intercepts system-wide hotkeys to capture audio and inject transcribed text into any active application with sub-second latency.
  • Integrated offline Speech-to-Text (STT) utilizing Faster-Whisper for high-accuracy, privacy-focused local transcription directly on the CPU.
  • Developed an on-the-fly AI text enhancement pipeline, allowing users to instantly rewrite and correct grammar of selected text using Groq (LLaMA 3) or local Ollama instances.
  • Built a multi-process desktop dashboard using Flask and Pywebview for real-time configuration, hotkey management, and dictation analytics.
  • Packaged and deployed the application as a standalone Windows executable using PyInstaller and Inno Setup for frictionless user installation.
