📌 What is Premium Matrimony?

Premium Matrimony is a modern online marriage platform designed specifically for Pakistani and South Asian users. It brings the traditional rishta process into the digital age — allowing users to create detailed profiles, discover compatible partners using AI, connect and chat in real time, and schedule meetings, all from one place.

What sets it apart is its use of Artificial Intelligence for intelligent vector-based matching, CNIC identity verification with OCR, and a RAG-powered help chatbot. A complete Admin Panel gives administrators full control over user management, report resolution, and CNIC verification approvals.

✨ User Features

Registration, Login & Security

  • • Sign up with username, email, and password
  • • 6-digit OTP sent to email for account verification
  • • Password reset via OTP email flow
  • • JWT-secured login sessions (industry standard)

Detailed Profile Creation

  • • Basic: full name, gender, date of birth, profile type (Individual or Guardian)
  • • Physical: height, weight, body type, complexion, disability
  • • Education: degree, field, university, graduation year
  • • Career: profession, job title, company, experience, work mode
  • • Financial: income range and currency
  • • Religion & Lifestyle: religion, sect, caste, family values, lifestyle habits
  • • Personality: personal bio, hobbies, personality tags
  • • Privacy: Public or Private visibility; profile picture + photo gallery
  • • Profile completion percentage shown on dashboard

Partner Preferences

  • • Preferred age range, marital status, location (city/country)
  • • Education level, profession, income range
  • • Religion, caste, lifestyle, family values
  • • Physical preferences: height range, body type, complexion
  • • Most valued qualities, deal-breakers, and optional personal message
  • • Drives the AI matching system

AI-Powered Matching

  • • Every user profile is converted to a mathematical vector (SentenceTransformers)
  • • Preference vector is compared against candidate profile vectors via ChromaDB
  • • Top 5 best matches suggested automatically on the dashboard
  • • AI generates a natural-language explanation of why each pair is compatible
  • • Learns from feedback: liked → shifts preference toward that type; disliked → shifts away

Search & Browse

  • • Filter profiles by age, city, country, education, profession, caste, religion
  • • Blocked users automatically hidden from search results
  • • Each profile card shows current connection status

Interest System (Rishta Requests)

  • • Send a formal interest request to any profile
  • • Receiver can accept or reject
  • • Mutual acceptance creates a matched connection
  • • Three organized tabs: Received, Sent, Matches

Real-Time Messaging

  • • Only matched users can message each other
  • • Instant delivery via WebSockets — no page refresh needed
  • • Text, images, videos, and documents (up to 10 MB)
  • • Unread message counts on dashboard; auto-marked read on open

Meeting Scheduler

  • • Schedule formal meetings with title, description, date, time, and optional location
  • • Other party can accept, reject, or cancel
  • • Four tabs: Received, Sent, Upcoming, History
  • • Upcoming meeting count shown on dashboard

CNIC Verification

  • • Upload front and back of Pakistani CNIC
  • • OCR (Pytesseract + EasyOCR) reads text from the images
  • • AI model parses raw OCR text to extract: name, DOB, CNIC number, gender, nationality
  • • Admin reviews with side-by-side profile comparison, then approves or rejects
  • • Verified profiles receive a visible approved badge and appear in search results

Blocking, Reporting & Visitors

  • • Block any user — they disappear from all parts of the platform (search, messages, meetings, visitors)
  • • View all blocked users and unblock at any time
  • • Report profiles for fake accounts, spam, harassment, or inappropriate content
  • • Profile visitor tracking — see who viewed your profile and when

AI Help Chatbot (RAG + Voice)

  • • Powered by RAG — answers from admin-uploaded documents (PDFs, FAQs, guidelines)
  • • Voice interaction: speak to the bot, audio is converted to text automatically
  • • Bot generates response and reads it aloud via text-to-speech

User Dashboard

  • • Profile completion percentage with prompts to fill missing info
  • • Profile visitors count, pending interest requests, unread messages, upcoming meetings
  • • AI-suggested top matches shown at a glance

Account Suspension & Appeals

  • • Suspended users receive email explaining the reason
  • • Users can submit an appeal with a written explanation
  • • Admin reviews and either reinstates (email notification sent) or keeps suspension

🛡️ Admin Panel Features

Dashboard & Analytics (30-day history)

  • • Daily new registrations, gender distribution, total matches made
  • • Messages sent, profile views, meetings scheduled
  • • Quick stats: total users, new users (24h), pending reports, pending verifications

User Management

  • • View all users with profile info and verification status
  • • Approve, ban (with reason), unban, or permanently delete users

Report Management

  • • Reports organized into Pending, Resolved, Dismissed tabs
  • • Full reported user profile shown alongside verification status and past report history
  • • Resolve, dismiss, or ban directly from the report page; add internal notes

CNIC Verification Management

  • • View uploaded CNIC images alongside AI-extracted data
  • • Side-by-side comparison with user profile: matching fields highlighted
  • • Manually re-trigger AI extraction if needed; approve or reject verification

AI Knowledge Base Management

  • • Upload PDFs and documents to the chatbot's RAG knowledge base
  • • Documents processed and stored in ChromaDB vector database
  • • Option to clear and refresh the entire knowledge base

🛠️ Tech Stack

Backend

Python, FastAPI, MySQL, JWT Authentication, SMTP via Gmail

Frontend

React.js with Vite, Tailwind CSS, Bootstrap, Framer Motion animations

AI & Matching

Groq API — Llama 3.3 70B, SentenceTransformers (local embeddings), ChromaDB (local vector DB)

CNIC Verification

Pytesseract + EasyOCR for text extraction, AI parsing of OCR output

Real-Time

WebSockets for instant messaging; no polling or page refresh

Chatbot

RAG pipeline with ChromaDB, voice input (STT) + TTS response
