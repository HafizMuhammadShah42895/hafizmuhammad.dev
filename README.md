## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone <repository-url>
cd ABC
```

### 2. Open in Browser
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 3. Or Run a Local Server
```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

## 🎛️ Customization

<details>
<summary><strong>Update Personal Information</strong></summary>

- Edit contact links in the hero and contact sections
- Replace the resume PDF file
- Update project entries in the `projectData` object

</details>

<details>
<summary><strong>Modify Brand Colors</strong></summary>
```javascript
// tailwind.config
colors: {
  'brand-blue':   '#2563eb',
  'brand-indigo': '#4f46e5',
}
```

</details>

<details>
<summary><strong>Add a New Project</strong></summary>
```javascript
// Append to projectData object
'project-id': {
  title: 'Project Title',
  desc:  'Short project description...',
  stack: 'Tech1, Tech2, Tech3'
}
```

</details>
