📌 Description

An intelligent voice-based ordering system for restaurants that uses conversational AI to take orders, answer questions, and manage deliveries. Built with Flask, LangGraph, and Groq LLM.

This project solves the problem of manual order taking in restaurants by providing an AI voice assistant that can understand natural language in multiple languages, take orders conversationally, validate delivery addresses, process payments, and send order confirmations.

✨ Key Features

Voice-Based Ordering

Natural conversation flow for placing orders

Multi-Language Support

English, Urdu, Arabic translation

AI-Powered Agents

Specialized agents for menu, orders, info

RAG Document Search

Upload PDFs for AI Q&A

Address Validation

Automatic distance calculation

Payment Integration

Stripe + Cash on Delivery

Email Notifications

Order confirmations with tracking

Admin Dashboard

Manage menu, orders, analytics

🛠️ Tech Stack

Backend

Python 3.13, Flask, Flask-SQLAlchemy, Flask-Login, Flask-Migrate, MySQL

AI & ML

LangGraph, LangChain, Groq API (llama-3.3-70b-versatile), Cartesia API (TTS), HuggingFace Embeddings (all-MiniLM-L6-v2), ChromaDB

Payment & Communication

Stripe, Flask-Mail, Geopy

Frontend

HTML5, CSS3, JavaScript, Bootstrap-inspired CSS, Font Awesome
