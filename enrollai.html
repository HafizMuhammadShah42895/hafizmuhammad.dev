📌 What is EnrollAI?

EnrollAI is a custom-built, multi-tenant SaaS platform that allows any business to effortlessly build and deploy AI chatbots for their website and WhatsApp. While serving as a universal customer communication tool, it also offers specialized modules for educational institutes—enabling them to automate student intake, answer course-specific queries using RAG, and instantly grade student CVs.

Web-Based Chat Widget

Embed a highly customizable, white-labeled AI chat widget directly onto the institute's website. Students can talk to the AI to find the right courses and get immediate answers.

WhatsApp Automation

Fully integrated with the Meta WhatsApp Business API to deploy the AI agent directly to students' phones, allowing them to inquire and enroll natively via WhatsApp.

✨ All Platform Features

User Authentication & Multi-Tenancy

  • • Each institution gets its own isolated account and dashboard.
  • • Complete data segregation ensures no cross-institute data leakage.

AI Knowledge Base (RAG) & Course Management

  • • Institutes can upload custom PDF/DOCX documents (prospectuses, syllabi) into a private ChromaDB vector database.
  • • Dynamic Course Builder: Add active courses with schedules, fees, deadlines, and eligibility criteria.
  • • The AI agent retrieves exact course details and institute rules during live conversations via RAG.

AI Agent Configuration & White-labeling

  • • Customize the AI agent's name (e.g., Alex) and conversational tone (Professional, Friendly, Assertive).
  • • Widget Builder: Fully customize the embedded web widget (colors, avatars, themes, typography) to match brand guidelines.

Intelligent Registration & CV Analysis

  • • Dynamic Form Builder: Create custom intake and registration forms per institution.
  • • Students can upload their CVs during chat; the AI analyzes the document against course requirements and assigns an automated "CV Score."
  • • Generates a detailed AI analysis report for the admissions team explaining why a candidate is or isn't a fit.

Omnichannel Conversational Pipeline

  • • WebSockets: Real-time, low-latency streaming chat interface for web users.
  • • WhatsApp API: Native integration for automated WhatsApp bot interactions.
  • • Powered by LangChain, LangGraph, and Groq (LLaMA 3.1) for fast, contextual, and memory-aware dialogue.

AI-Powered Session Analytics & Token Tracking

  • • Auto-generated session summaries and sentiment analysis (Positive, Neutral, Negative) after every interaction.
  • • Automatic outcome classification (e.g., Enrolled, Interested, Query Answered).
  • • Granular AI Usage Logging: Tracks prompt/completion tokens, latency, and estimated LLM costs on a per-feature and per-company basis.
